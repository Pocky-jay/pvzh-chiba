# 相关问题解答

## 这是什么版本？

千叶重铸版是基于官方原版 1.67.8 的个人改版，只调整数据层（卡牌数值、机制、文本、稀有度等），不改动程序本体。

## 是官方版本吗？

不是。本版为个人制作，与官方无关联。

## 支持联机吗？

不支持。本版面向**单机 / PvE**，不涉及联机内容。

## 需要 root 吗？

安装 APK 不需要 root。

## 从哪里下载？网盘链接失效怎么办？

下载地址见[下载游戏](/install/download)。网盘链接会随版本更新替换；若链接失效或提取码错误，请在[联系反馈](/contact)留言，会尽快补链。

## 安装后存档还在吗？

待补充。安装包签名与原版不同，通常无法直接覆盖安装；卸载会清除本地存档，操作前请先备份。

## 能和原版共存吗？

待补充。

## 更新会覆盖我的改动吗？

待补充。

## 还有别的问题？

请通过[联系反馈](/contact)提交。
