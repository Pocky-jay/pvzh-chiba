# 安装教程

> 截图待补充（统一放在 `/images/screenshots/`）。

## 安装前

1. **备份存档**：卸载或重装前，先确认存档已备份或已同步。
2. **检查空间**：预留足够的存储空间用于安装与首次资源下载。

## 安装步骤

### 1. 下载安装包

从[下载页](/install/download)获取 APK 文件。

### 2. 允许安装未知来源应用

在系统设置中允许当前文件管理器或浏览器安装应用。

### 3. 安装

点击 APK 完成安装。若提示与已安装版本冲突，需先卸载原版（注意先备份存档）。

### 4. 首次启动

首次启动需要下载游戏资源，请保持网络连接并耐心等待。

### 5. 进入游戏

资源下载完成后进入游戏，确认版本信息。

## 遇到问题

安装或启动失败时，请查看[相关问题解答](/faq)，或通过[联系反馈](/contact)提交问题。
